# Notes Frontend: Usage

- API base URL resolution:
  1. REACT_APP_API_BASE
  2. REACT_APP_BACKEND_URL
  3. http://localhost:4000 (default)

- Keyboard shortcuts:
  - Ctrl/Cmd + S: Save current note
  - Delete: Delete current note

- Theme:
  - Ocean Professional with retro amber accents
  - Toggle from Sidebar or Topbar
